퍼셉트론 · 하나의 W와 b로 판정

퍼셉트론은 입력의 가중합을 계산하고, Step 함수로 0 또는 1을 결정하는 뉴런 하나입니다.

가중합 → 비선형성
이 예시: w₁=w₂=W
z=W(x₁+x₂)+b일반 뉴런은 입력마다 다른 Weight 가능
z=w₁x₁+w₂x₂+b

뉴런이 하나여도 연결별 Weight는 여러 개입니다. 여기서는 두 Weight를 같은 값으로 묶었고, Step은 z≥0이면 1, 아니면 0을 냅니다.

Step은 0/1 판정용 예시입니다. 같은 Architecture의 ReLU는 뒤에서 별도로 확대합니다.

AND Gate · Weight와 Bias로 직선 이동

두 입력 x₁, x₂를 구분하는 결정 직선입니다. W를 바꾸면 기울기가 회전하고, b를 바꾸면 위치가 이동합니다.

ReLU의 이유

① W · Bias 조절

z=Wx₁+1·x₂+b → 경계 x₂=−Wx₁−b (x₂의 Weight=1 고정)

앞의 공통 W 예시와 다른 설정입니다. w₂=1 고정, w₁=W 조절로 W는 기울기를, b는 y절편을 바꿉니다.

② 직선과 AND 정답 비교

점 안의 0/1 = 정답 · 연한 초록 영역 = AI가 1로 판단한 위치

AND는 (1,1)만 1이어서 두 입력 Weight를 갖는 뉴런 하나의 직선만으로 네 점을 분리할 수 있습니다.

비선형성 · 깊어져도 직선이면?

가중합(Affine) 계산만 반복하면 하나의 가중합으로 다시 합칠 수 있습니다. 층을 늘리는 것만으로 XOR의 한계를 넘지는 못합니다.

ReLU의 이유

① 가중합 두 층을 연결

h = W₁x + b₁
z = W₂h + b₂

z = W₂(W₁x+b₁)+b₂

최종 경계는 여전히 한 직선

② 전개하면 하나의 계산

z = (W₂W₁)x
　 + (W₂b₁+b₂)

새 Weight = W₂W₁
새 Bias = W₂b₁+b₂

중간에 비선형 변환을 넣으면
하나의 Affine으로 합칠 수 없습니다.

두 층의 Weight와 Bias를 바꾸면 경계의 기울기와 위치가 달라집니다. 그래도 한 직선입니다. 다음은 반응을 꺾는 ReLU입니다.

ReLU · 비선형성의 시작

ReLU는 음수는 0으로, 0 이상은 그대로 통과시킵니다. 같은 축과 같은 눈금에서 0의 꺾임을 비교합니다.

ReLU 확대

ReLU(z)=max(0,z)는 0에서 꺾이는 비선형 함수입니다. 여러 반응을 조합하면 한 직선보다 복잡한 패턴을 표현할 수 있습니다.

단일 ReLU 하나만으로 XOR이 바로 해결되는 것은 아닙니다. 다음 실습은 두 ReLU를 조합한 |t|의 효과를 비교합니다.

XOR · 선형층을 쌓아도 직선 하나

가중합만 연결하면 경계의 기울기·위치는 바뀌어도 한 직선입니다. |t|를 사이에 넣어 꺾이는 경계와 비교합니다.

ReLU 효과

Layer 1

t=W₁x₁+x₂+b₁

Layer 2

z=W₂g(t)+x₁+b₂

g(t)=t일 때: z=(W₂W₁+1)x₁+W₂x₂+(W₂b₁+b₂)

점 안의 0/1 = 정답 · 연한 초록 영역 = AI가 1로 판단한 위치

|t|=ReLU(t)+ReLU(−t)는 두 ReLU 반응의 조합입니다. CNN도 Conv 사이의 비선형성으로 복잡한 패턴을 표현합니다.

모델 학습 · 오차를 줄이는 반복

학습은 모델 내부의 숫자 Weight(가중치)를 바꾸는 과정입니다. 먼저 사진 대신 입력 x=2, 정답 y=4인 아주 작은 회귀 문제로 원리를 확인합니다.

이 예시는 하나의 숫자를 예측하는 회귀입니다. 사과 결함 분류도 예측과 정답의 차이로 가중치를 바꾸지만 Task에 맞는 다른 Loss를 사용합니다.

Overfitting · 새 데이터 일반화

Overfitting(과적합)은 학습 데이터에 지나치게 맞춰 새 데이터 성능이 떨어지는 현상입니다. Validation 추세와 실패 사례를 함께 봅니다.

Generalization(일반화)은 직접 학습하지 않은 데이터에서도 성능을 유지하는 능력입니다.

IoU · 박스 겹침 비율

분류의 정답 여부와 달리, 검출·분할에서는 위치나 영역도 맞아야 합니다. IoU(Intersection over Union)는 정답과 예측의 교집합/합집합 비율입니다.

완전 일치하면 1, 겹치지 않으면 0입니다. IoU만으로 검출 성능 전체를 판단하지 않습니다. 클래스·놓침·중복까지 평가하는 mAP(평균 정밀도 요약 지표) 등도 사용합니다.
