규칙 기반 · 답을 구하는 방법을 사람이 정한다

앞 장에서 무엇을 판단할지 정했습니다. 이제 어떻게 판단할지 생각해 봅시다. 더하기는 사람이 규칙을 명확하게 알려줄 수 있습니다.

예시 ①

1+1=2

첫 번째 입력도 같은 덧셈 규칙

예시 ②

2+1=3

숫자만 달라져도 계산 방법은 동일

사람이 작성한 규칙→결과 = 첫 번째 수 + 두 번째 수

계산 규칙이 명확하면 데이터를 학습하지 않고도 정확하게 처리할 수 있습니다.

규칙 기반(Rule-based)은 사람이 입력에서 결과까지의 판단 방법을 직접 작성하는 방식입니다. 그렇다면 사진의 작은 결함은 어떤 규칙으로 판단해야 할까요?

같은 교육용 사과 사진의 밝기만 바꾼 비교 · 오른쪽은 지도학습(Supervised Learning)의 개념이며 실제 모델 예측 결과가 아닙니다.

규칙 기반은 사람이 판단 기준을 직접 작성하고, 머신러닝은 데이터에서 판단 기준을 학습합니다. 단순한 규칙이면 규칙 기반이 유용하고, 이미지처럼 변화가 복잡할 때 학습이 도움이 됩니다.

퍼셉트론 · 하나의 W와 b로 판정

퍼셉트론(Perceptron)은 입력을 계산한 뒤 Step 함수로 0 또는 1을 결정하는 뉴런 하나입니다. 여기서는 가장 쉬운 예시로 두 입력에 같은 W를 적용합니다.

설명용 · 두 입력에 공통 Weight W 적용z = W(x₁ + x₂) + b

W는 입력에 곱하는 가중치, b는 판단 기준을 옮기는 Bias(편향)입니다. Step(z)가 최종 0/1을 정합니다.

여기서 W 하나는 두 입력의 가중치를 같게 묶은 쉬운 예시입니다. 실제 뉴런의 W는 입력별 여러 가중치를 묶어 나타낼 수도 있습니다. 다음 AND Gate 규칙을 이 계산으로 표현할 수 있습니다.

AND Gate · Weight와 Bias로 직선 이동

두 입력 x₁, x₂를 구분하는 결정 직선입니다. W를 바꾸면 기울기가 회전하고, b를 바꾸면 위치가 이동합니다.

① W · Bias 조절

z=Wx₁+1·x₂+b → 경계 x₂=−Wx₁−b (x₂의 Weight=1 고정)

여기서는 w₂=1로 고정하고 w₁=W만 조절합니다. 따라서 W는 기울기(−W)를, b는 y절편(−b)을 바꿉니다.

② 직선과 AND 정답 비교

점 안의 0/1 = 정답 · 연한 초록 영역 = AI가 1로 판단한 위치

AND는 (1,1)만 1이어서 두 입력 Weight를 갖는 뉴런 하나의 직선만으로 네 점을 분리할 수 있습니다.

AND는 (1,1)만 1 · XOR는 (0,1), (1,0)이 1 · 초록색 두 사례가 대각선으로 위치합니다.

XOR의 1과 0은 직선 하나로 분리할 수 없습니다. 다음 슬라이드에서 W·b를 움직여도 선형층만으로는 안 되는 이유를 확인합니다.

XOR · 선형층을 쌓아도 직선 하나

XOR 정답은 (0,1), (1,0)만 1입니다. 두 선형층의 W를 바꿔도 최종 경계는 하나의 직선으로 기울기만 달라질 뿐입니다.

① Layer별 W · Bias

Layer 1 · W₁x₁ + 1·x₂ + b₁

t=W₁x₁+1·x₂+b₁ · x₂의 Weight는 1로 고정

Layer 2 · W₂t + 1·x₁ + b₂

z=W₂t+1·x₁+b₂ · x₁ Weight=1 고정 · 각 층에서 Weight 하나만 조절

② 최종 결정 경계

점 안의 0/1 = 정답 · 연한 초록 영역 = AI가 1로 판단한 위치

선형층을 여러 개 쌓아도 XOR는 분리할 수 없습니다. 그래서 층 사이에 비선형성을 넣습니다. 여기서는 |t|로 보여주며, |t|는 두 ReLU 반응의 합으로 구현할 수 있습니다.

ReLU · 비선형성의 시작

Activation Function(활성화 함수)은 계산에 비선형성을 넣습니다. ReLU는 입력이 0보다 작으면 0, 크면 입력값을 그대로 출력합니다.

차이는 음수 입력. 직선은 −2를 −2로 전달하지만, ReLU는 0으로 자릅니다. 이 꺾임을 조합하면 하나의 직선으로 표현할 수 없는 반응을 만들 수 있습니다.

ReLU가 0에서 반응을 꺾는 성질을 여러 뉴런에 조합하면, 한 직선보다 복잡한 패턴을 표현할 수 있습니다.

비선형성 · 깊어져도 직선이면?

더하고 곱하는 층을 여러 개 연결해도 한 번의 Affine 변환으로 합칠 수 있습니다. 중간의 ReLU가 이 한계를 바꿉니다.

ReLU가 없는 여러 층

전체가 하나의 Affine 계산과 동등

층 사이에 ReLU

구간에 따라 다르게 반응하는 함수를 조합

단순 그림은 이해용 도식이며 실제 신경망의 측정 그래프가 아닙니다. Step과 ReLU는 모두 비선형이고, 실제 신경망은 보통 ReLU 같은 활성화를 여러 층에서 반복합니다.

CNN에서도 작은 영역의 가중합(Conv) 사이에 ReLU를 넣어 더 복잡한 패턴을 표현합니다.

CNN Architecture · 사진에서 분류까지

Convolutional Neural Network(CNN, 합성곱 신경망)는 Convolution으로 특징을 추출하고, 마지막 분류기로 결과를 만듭니다. 전체 구조를 먼저 살펴봅니다.

사진 → Feature Extractor(Convolution/Pooling) → Classification Head. 이어서 Convolution의 Kernel이 무엇을 계산하는지 확대합니다.

Max Pooling · 영역별 최댓값

왜 Max Pooling을 사용할까요? 특징의 강한 반응은 남기면서 Feature Map의 공간 크기를 줄여 다음 층의 연산 부담을 낮춥니다.

입력 Feature Map · 4×4

1324561242930781

Max Pooling 2×2, Stride 2

4×4 (16칸) → 2×2 (4칸)

반응의 세기는 남지만 정확한 위치·다른 값은 사라집니다.

사용 이유: 4×4(16칸) → 2×2(4칸)으로 계산·저장 부담을 줄입니다. 작은 위치 변화에는 덜 민감해질 수 있지만, 정확한 위치와 나머지 값은 잃습니다.

각 채널에 따로 적용하며 공간 크기가 가로·세로 각각 절반이 됩니다. Pooling은 고정된 Max 연산이므로 학습하는 Kernel이 아닙니다.

실제 Feature Map · CNN 내부 반응

실제 계산된 반응을 보기 위해 강아지 사진 자료를 사용합니다. ImageNet 사전학습 SqueezeNet 1.1의 출력이며, 사과 결함 모델의 결과가 아닙니다.

Feature Map은 RGB 사진이 아니라 학습한 특징에 대한 위치별 반응값입니다. 색상은 채널별 상대값으로 조정했으므로 채널 사이의 절대 크기는 비교할 수 없습니다.

입력 사진: Stanford CS231n · 2017 Lecture 5, Slide 37 · 강아지 영역 자르기·크기 조정. Feature Map은 직접 계산한 실제 모델 출력이며 각 층의 일부 채널입니다.

Backbone과 Task Head

같은 사과 사진에서 특징을 모으는 부분이 Backbone입니다. 갈색 반점의 유무(Class)·위치(Box)·모양(Mask)에 따라 마지막 Task Head를 선택합니다.

세 가지 Head는 구조 비교를 위한 개념도입니다. 실제 한 모델이 항상 세 Task를 동시에 출력하는 것은 아닙니다.

모델 학습 · 오차를 줄이는 반복

학습은 모델 내부의 숫자 Weight(가중치)를 바꾸는 과정입니다. 먼저 사진 대신 입력 x=2, 정답 y=4인 아주 작은 회귀 문제로 원리를 확인합니다.

이 예시는 하나의 숫자를 예측하는 회귀입니다. 사과 결함 분류도 예측과 정답의 차이로 가중치를 바꾸지만 Task에 맞는 다른 Loss를 사용합니다.

Overfitting · 새 데이터 일반화

Overfitting(과적합)은 학습 데이터에 지나치게 맞춰 새 데이터 성능이 떨어지는 현상입니다. Validation 추세와 실패 사례를 함께 봅니다.

Generalization(일반화)은 직접 학습하지 않은 데이터에서도 성능을 유지하는 능력입니다.

검사의 목적이 불량을 찾는 것이라면 전체 Accuracy만이 아니라 놓친 불량(FN)과 Recall을 봐야 합니다.

Precision과 Recall

직전 혼동행렬의 TP=18·FP=4·FN=2를 그대로 사용합니다. Precision은 불량이라고 알린 22건, Recall은 실제 불량 20건을 분모로 계산합니다.

IoU · 박스 겹침 비율

분류의 정답 여부와 달리, 검출·분할에서는 위치나 영역도 맞아야 합니다. IoU(Intersection over Union)는 정답과 예측의 교집합/합집합 비율입니다.

완전 일치하면 1, 겹치지 않으면 0입니다. IoU만으로 검출 성능 전체를 판단하지 않습니다. 클래스·놓침·중복까지 평가하는 mAP(평균 정밀도 요약 지표) 등도 사용합니다.
