12 · CNN 핵심 개념

CNN의 지역 연결과 가중치 공유

CNN은 작은 영역에 같은 Kernel 가중치를 여러 번 적용합니다. 그래서 사진의 위치가 달라도 비슷한 경계·질감 패턴을 찾는 데 유리합니다.

지역 연결: 주변 Pixel을 묶어 특징을 계산합니다. 가중치 공유: 위치를 옮겨도 동일한 Kernel을 사용합니다. 단, 모든 이동·크기 변화에 자동으로 완벽히 대응하는 것은 아닙니다.

13 · Kernel의 이동 심화 학습

Kernel · 작은 영역을 반복 탐색

Kernel(커널)은 작은 숫자 가중치 배열입니다. 사진 위를 이동하면서 이웃 Pixel과 곱하고 더해 위치별 특징 반응을 계산합니다. 그림에서는 같은 3×3 값을 여러 위치에 반복 적용합니다.

왜 필요할까? 사진 전체를 한꺼번에 암기하는 대신 작은 영역의 경계·질감 등 국소 패턴을 반복해서 찾기 위해서입니다. CNN에서는 Kernel의 숫자가 학습으로 조정됩니다.

이해 참고: Stanford CS231n · Convolutional Networks · 입력 강아지 사진은 CS231n 강의 원본, 특징 지도는 원리를 보여주는 개념도입니다.

선택: 3×3 Kernel이 실제 숫자를 계산하는 과정

3×3 Kernel은 사진의 위치마다 같은 숫자 가중치를 적용합니다. 본강의에서 결과 숫자를 직접 계산할 필요는 없습니다.

Kernel의 역할: 특정 모양·방향·질감에 반응하는 특징 추출기입니다. 아래 예시는 사람이 정한 경계 Kernel이며, 실제 CNN은 학습된 다양한 Kernel을 사용합니다.

15 · 고정/학습 필터실전 개념

고정 필터와 학습 Kernel

전통적인 Mean·Gaussian·Sobel 필터는 사람이 계산 규칙을 미리 정합니다. 반면 CNN의 Convolution Kernel은 초기 값에서 출발해 정답과 예측 오차를 줄이도록 학습 중 조정됩니다.

차이점: 고정 필터는 정해진 연산을 수행하고, 학습 Kernel은 데이터에 유용한 패턴이 무엇인지 가중치를 조정합니다. Kernel 하나가 특정 객체 전체를 이해한다는 뜻은 아닙니다.

__SEQ__ · AND · XOR핵심 개념

AND는 직선, XOR는 직선만으로 불가

입력 x₁, x₂가 각각 0 또는 1일 때, 초록 점(정답 1)과 주황 점(정답 0)을 나누는 경계를 비교합니다.

AND · 둘 다 1일 때만 1

하나의 직선으로 가능 가중합 x₁+x₂와 임계값 1.5로 분류할 수 있습니다.

XOR · 서로 다를 때만 1

직선 하나로 불가능 정답 1이 대각선으로 분리되어 꺾인 경계가 필요합니다.

왜 비선형성을 넣을까? 단일 직선으로 해결할 수 없는 XOR 같은 패턴을 표현하기 위해서입니다.

가중합 다음의 최종 Threshold는 분류 결정을 만들지만 경계는 여전히 직선입니다. Goodfellow et al., Deep Learning, Ch. 6 · 직접 작성한 2D 논리 게이트 그림.

__SEQ__ · ReLU핵심 개념

ReLU · XOR를 표현하는 비선형 조합

ReLU(z)=max(0,z)는 음수를 0으로 바꾸는 비선형 함수입니다. XOR의 두 경우를 서로 다른 중간 뉴런이 나눠 표현할 수 있습니다.

중간 Layer · 두 ReLU 뉴런
x₁, x₂→h₁ = ReLU(x₁−x₂)
h₂ = ReLU(x₂−x₁)
출력 y = h₁ + h₂

두 입력이 같으면 0, 서로 다르면 1이 됩니다. 이 예제는 0/1 입력에 대한 정확한 XOR 계산입니다.

같은 입력, 실제 출력 비교
x₁x₂h₁h₂y(XOR)
00000
01011
10101
11000

ReLU가 없으면 두 중간 계산도 하나의 가중합으로 합쳐져 XOR 패턴을 만들 수 없습니다.

비선형 활성화 함수는 Layer 사이의 계산을 꺾어 한 직선 이상의 복잡한 판단 경계를 표현할 수 있게 합니다.

위 식은 XOR의 최소 개념 예제이며 실제 CNN 전체 구조를 뜻하지 않습니다. Deep Learning, Ch.6.

__SEQ__ · 선형성핵심 개념

비선형성이 없으면 여러 Layer도 한 Layer

Layer마다 Weight와 Bias를 사용하는 Affine(선형 변환+편향) 계산을 아무리 반복해도, 중간 활성화 함수가 없으면 하나의 Affine 변환으로 합칠 수 있습니다.

중간에 ReLU가 없다면
입력 x→W₁x+b₁→W₂z+b₂→출력 y
y = W₂(W₁x+b₁)+b₂ = (W₂W₁)x + (W₂b₁+b₂)

W₃, W₄… 를 더 쌓아도 최종적으로 y=Wx+b 꼴입니다. 중간 층이 많아져도 최종 판정 경계는 하나의 직선/평면을 벗어나지 못합니다.

비선형성 없음

여러 층 ≡ 한 Affine 층

AND는 구별할 수 있어도, XOR처럼 두 영역이 떨어진 패턴은 한 직선으로 나눌 수 없습니다.

중간에 ReLU 추가

층을 합칠 수 없음

입력에 따라 일부 뉴런의 출력이 0이 되면서, 여러 직선 조각을 조합해 XOR를 표현할 수 있습니다.

깊이 자체가 아니라 Layer 사이의 비선형성이 복잡한 패턴을 학습할 표현력을 만듭니다.

엄밀히는 Weight와 Bias를 포함한 여러 Affine 변환의 합성이 단일 Affine 변환이라는 뜻입니다. 최종 Threshold만 추가해도 XOR는 분리할 수 없습니다.

21 · CNN 학습 핵심 개념

학습 과정에서 바뀌는 Kernel

학습은 사진 입력 → 현재 Kernel로 특징 추출 → 예측 → 정답과 비교(Loss) → 가중치 수정의 반복입니다. 정답에 더 도움이 되도록 여러 Kernel 값이 함께 조정됩니다.

학습의 영향: 같은 사진이라도 Kernel 가중치가 바뀌면 Feature Map과 최종 예측이 달라질 수 있습니다. Gradient로 수정 방향을 계산하고 Optimizer가 가중치를 갱신합니다.

22 · CNN 구조핵심 개념

CNN 블록 · Conv와 활성화

CNN 블록은 Convolution으로 특징을 만들고 ReLU 같은 활성화 함수를 사용해 복잡한 표현을 학습합니다. 일부 구조는 Batch Normalization(배치 정규화)을 추가합니다.

핵심은 Kernel의 특징 추출과 여러 층의 조합입니다. BatchNorm의 세부 계산은 이 입문 강의에서 생략합니다. 모든 CNN이 그림과 동일한 순서·구조인 것은 아닙니다.

23 · Feature Map 핵심 개념

Feature Map · 위치별 반응값

Kernel을 사진의 여러 위치에 적용해 얻은 반응값을 순서대로 놓으면 Feature Map(특징 지도)이 됩니다. 그림 속 5×5·3×3 수치는 연산 방법을 이해하기 위한 작은 예시입니다.

Feature Map은 각 위치에서 얼마나 반응했는지를 숫자로 표현합니다. 실제 CNN에서는 여러 Kernel의 출력이 채널로 쌓입니다. 자세한 계산은 선택적으로 살펴보면 됩니다.

Stride · 이동 간격과 출력 크기

왜 사용할까? 필터의 계산 위치를 건너뛰어 Feature Map의 가로·세로 크기와 연산량을 줄이기 위해서입니다.

입력 · 5×5

12345678910111213141516171819202122232425

입력 25개 값 · 예시 Grayscale 데이터

Stride 1 → 3×3

789121314171819

출력 9개 · 이웃 3×3 평균을 1칸씩 이동

Stride 2 → 2×2

791719

출력 4개 · 같은 필터를 2칸씩 이동

같은 3×3 평균 Kernel · Padding 0 · 출력값은 실제로 계산한 평균(예: 첫 칸 7)

Stride 1: 5×5 → 3×3 / Stride 2: 5×5 → 2×2. 크기는 줄지만 일부 위치의 세부 반응은 놓칠 수 있습니다.

계산 예시: 5×5 숫자와 고정 평균 Kernel. CNN의 학습된 특징값이 아니라 Stride의 출력 크기 변화를 설명합니다. 출처: Stanford CS231n · Convolutional Networks.

__SEQ__ · Padding핵심 개념

Padding · 경계 계산과 크기 유지

왜 사용할까? 가장자리 Pixel도 Kernel의 중심으로 계산하고, 여러 Layer를 거치며 공간 크기가 너무 빨리 줄지 않도록 하기 위해서입니다.

입력 · 3×3

123456789

원본 9개 숫자

Padding 1 → 5×5

0000001230045600789000000

테두리 1칸을 0으로 추가

출력 · 3×3

122116274533243928

3×3 합계 Kernel · Stride 1

Padding 0이면 출력 1×1 [45] · Padding 1이면 출력 3×3 (같은 입력 크기 유지)

Padding은 새 정보를 만들어 내지 않습니다. 0을 덧붙여 경계에서도 필터를 적용하며, 출력 크기와 가장자리의 계산값이 달라집니다.

입력 1~9, 3×3 가중치가 모두 1인 합계 Kernel의 정확한 숫자 예시입니다. 실제 CNN의 Padding 값은 설정에 따라 다릅니다. Stanford CS231n.

Max Pooling · 강한 반응만 남기기

왜 사용할까? 이웃 영역에서 가장 큰 Feature 반응을 선택해 위치 정보를 압축하고, 다음 Layer가 처리하는 데이터 양을 줄이기 위해서입니다.

입력 Feature Map · 4×4

1324587621903456

16개 위치 · 학습값이 아닌 설명용 숫자

→

2×2 Max Pool → 2×2

8749

4개 위치 · 각 2×2 영역의 최댓값

16칸 → 4칸

왼쪽 위 2×2 영역 [1, 3; 5, 8] → 최댓값 8만 남습니다.

공간 위치 수 75% 감소, 채널 수는 그대로. 강한 반응은 남지만, 정확한 위치와 작은 특징은 일부 손실됩니다.

2×2 Pool·Stride 2·Padding 0 예시. Max Pooling은 가중치를 학습하지 않는 연산이며, 모든 CNN이 반드시 사용하는 것은 아닙니다. Stanford CS231n.

28 · Backbone과 Head 핵심 개념

Backbone과 Task Head

같은 입력 특징을 추출하는 Backbone과, Classification·Detection·Segmentation 가운데 필요한 결과를 만드는 Task Head를 구분합니다.

세 가지 Head는 구조 비교를 위한 개념도입니다. 실제 한 모델이 항상 세 Task를 동시에 출력하는 것은 아닙니다.

29 · 학습의 의미 핵심 개념

모델 학습 · 오차를 줄이는 반복

입력 x=2, 정답 y=4를 고정하고 학습을 진행합니다. 모델이 예측 오차를 줄이도록 가중치를 자동으로 수정하는 과정을 관찰하세요.

학습의 목적은 사람이 Weight를 임의로 조작하는 것이 아니라, 예측과 정답의 오차를 줄이도록 알고리즘이 Parameter를 갱신하는 것입니다.

30 · Loss 핵심 개념

Loss · 예측과 정답의 차이

정답 y=4를 고정하고 후보 예측 2·3.6·4를 비교합니다. 회귀용 제곱오차는 차이의 부호를 없애고, 큰 오차에 더 큰 Loss를 부여합니다.

여러 샘플의 제곱오차를 평균하면 MSE(Mean Squared Error, 평균제곱오차)입니다. 문제에 따라 다른 Loss를 사용합니다.

31 · Training Loop 핵심 개념

Forward · Gradient · Weight 갱신

Training(학습)은 한 번의 계산으로 끝나지 않습니다. 바뀐 가중치로 다음 예측을 계산하고 다시 오차를 줄입니다.

Forward는 예측 계산, Backward는 Gradient 계산, Update는 가중치 수정입니다.

32 · Training과 Inference 핵심 개념

Training과 Inference의 차이

Inference(추론)는 학습된 모델에 새 입력을 넣어 결과를 얻는 과정입니다. 정답 없이도 예측할 수 있습니다.

추론 과정 자체는 새로운 데이터로 가중치를 학습하는 과정이 아닙니다.

33 · Batch·Iteration·Epoch 핵심 개념

Batch · Iteration · Epoch

Batch는 한 번에 처리하는 묶음, Iteration은 보통 한 묶음의 처리, Epoch은 학습 데이터 전체를 한 번 보는 주기입니다.

이미지 10장, batch_size=4, 마지막 묶음을 버리지 않으면 4+4+2의 3번 처리가 1 Epoch입니다.

34 · Dataset 핵심 개념

데이터셋 · 촬영 조건과 Label

Dataset(데이터셋)은 학습·평가에 사용하는 데이터 모음입니다. 조명·크기·배경·설비·시간대와 일관된 정답 기준을 확인합니다.

특정 배경만 정답과 함께 반복되면, 모델이 물체 대신 배경으로 판단할 수 있습니다.

35 · 데이터 분리 핵심 개념

Train · Validation · Test

Train은 가중치 학습, Validation은 모델·설정·Threshold 선택, Test는 최종 일반화 평가에 사용합니다.

예: 1,000장의 70/15/15 분리. 비율보다 서로 독립적인 평가 데이터 확보가 중요합니다.

36 · Group Split 핵심 개념

Video Group Split · 데이터 누출 방지

동일한 원본 영상 A·B·C에서 각각 3개 Frame을 뽑은 예시입니다. 무작위 Frame 분할과 원본 Video를 통째로 나누는 Group Split을 비교합니다.

같은 원본 영상의 Frame이 Train·Validation·Test에 동시에 들어가지 않게 합니다. 새 설비 성능을 평가하려면 설비 자체로 Group을 정합니다.

37 · 전처리 핵심 개념

Preprocessing · 입력 규격 맞추기

동일 사진을 강제로 정사각형으로 늘린 결과와 비율을 유지한 Letterbox를 비교합니다.

비율을 고려하지 않은 Resize는 객체 형태를 왜곡합니다. 전처리에서는 크기뿐 아니라 RGB/BGR, 값의 정규화, 채널 순서를 학습 때와 동일하게 맞춥니다.

38 · Data Augmentation 핵심 개념

Data Augmentation · 조건 변화 만들기

동일 강아지 사진에 밝기·회전·가림을 실제 적용했습니다. 그림은 학습 결과가 아니라 입력 데이터의 변화입니다.

현실적인 변형으로 학습 조건을 넓힙니다. Detection·Segmentation에서 회전 등 공간 변형을 주면 Bounding Box·Mask도 함께 갱신해야 합니다.

39 · Transfer Learning 핵심 개념

Transfer Learning · 사전학습 활용

사전학습으로 얻은 Backbone 가중치를 새 Task의 출발점으로 사용합니다. 새로운 Label에 맞춘 Head를 준비하고 대상 데이터에서 추가 학습합니다.

내 데이터가 사전학습 데이터와 다르면 효과가 달라질 수 있으므로 별도 평가가 필요합니다.

40 · Freeze와 Fine-tuning 심화 학습

Freeze와 Fine-tuning

Freeze 방식은 Backbone 가중치를 고정하고 Head를 학습합니다. Fine-tuning에서는 선택한 Backbone 가중치까지 업데이트합니다.

같은 대상 데이터로 두 방식을 검증하고, 데이터 양·도메인 차이·Validation 성능에 따라 업데이트 범위를 선택합니다.

41 · Overfitting 핵심 개념

Overfitting · 새 데이터 일반화

Overfitting(과적합)은 학습 데이터에 지나치게 맞춰 새 데이터 성능이 떨어지는 현상입니다. Validation 추세와 실패 사례를 함께 봅니다.

Generalization(일반화)은 직접 학습하지 않은 데이터에서도 성능을 유지하는 능력입니다.

42 · Threshold 핵심 개념

Score Threshold · 판정 기준

설명용 불량 점수 0.82를 기준 0.50과 0.90에 각각 적용합니다. 점수는 같아도 판정 결과는 바뀝니다.

임계값을 바꾸면 불량 미검과 오알람 수가 달라질 수 있습니다. 기준은 Validation에서 선택하며, 점수 0.82는 다음 100개 평가 사례와 별개입니다.

43 · Confusion Matrix 핵심 개념

Confusion Matrix · 100건 평가

총 100건의 같은 평가 데이터를 다음 지표 계산까지 이어갑니다. 실제 불량 20건 중 18건을 찾고, 정상 80건 중 4건을 잘못 알렸습니다.

TP: 찾은 불량 / FN: 놓친 불량 / FP: 오알람 / TN: 정상 통과.

44 · Precision과 Recall 핵심 개념

Precision과 Recall

직전 혼동행렬의 TP=18·FP=4·FN=2를 그대로 사용합니다. Precision은 불량이라고 알린 22건, Recall은 실제 불량 20건을 분모로 계산합니다.

동일한 TP=18이어도 Precision=18/22=81.8%, Recall=18/20=90%입니다. 임계값이 바뀌면 두 지표도 변할 수 있습니다.

45 · IoU 핵심 개념

IoU · 박스 겹침 비율

IoU(Intersection over Union, 교집합/합집합 비율)는 정답 영역과 예측 영역의 겹침 정도입니다.

완전 일치하면 1, 겹치는 영역이 없으면 0입니다.

46 · 평가와 실패 사례 핵심 개념

Grad-CAM · 클래스별 판단 근거

같은 사진을 보더라도 모델에 ‘개’와 ‘고양이’ 중 무엇을 설명하도록 요청하는지에 따라 강조되는 영역이 달라집니다. 실제 공개 Grad-CAM 구현 결과를 비교합니다.

높은 Score만으로 올바른 근거를 사용했다고 보장할 수 없습니다. Grad-CAM은 분류 결정과 관련된 영역을 살펴보는 보조 도구이며, 결함의 정답 Box·Mask를 뜻하지 않습니다.

연구: Selvaraju et al., Grad-CAM, ICCV 2017 · 실제 Figure: jacobgil/pytorch-grad-cam 공식 구현 예시 · 원본 이미지 3장을 픽셀 변경 없이 저장소에 보존해 사내망에서도 로드합니다. 모델 출력 점수는 이 그림에 표시하지 않았습니다.

47 · 운영 Cycle 핵심 개념

Vision AI 프로젝트 전체 흐름

Vision Task별 성공 기준(분류 판정·Box 위치·Mask 품질)을 정하고, 운영 중 수집한 오류를 Label 검토 및 재평가로 연결합니다.

운영 Cycle에서는 Task별 Metric·오류 이미지·촬영 조건을 함께 추적하고, 개선 전후를 같은 기준으로 다시 평가합니다.

운영 데이터와 재학습
