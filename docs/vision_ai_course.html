퍼셉트론 · 하나의 W와 b로 판정

퍼셉트론은 입력의 가중합을 계산하고, Step 함수로 0 또는 1을 결정하는 뉴런 하나입니다.

가중합 → 비선형성
이 예시: w₁=w₂=W
z=W(x₁+x₂)+b일반 뉴런은 입력마다 다른 Weight 가능
z=w₁x₁+w₂x₂+b

뉴런이 하나여도 연결별 Weight는 여러 개입니다. 여기서는 두 Weight를 같은 값으로 묶었고, Step은 z≥0이면 1, 아니면 0을 냅니다.

Step은 0/1 판정용 예시입니다. 같은 Architecture의 ReLU는 뒤에서 별도로 확대합니다.

AND Gate · Weight와 Bias로 직선 이동

두 입력 x₁, x₂를 구분하는 결정 직선입니다. W를 바꾸면 기울기가 회전하고, b를 바꾸면 위치가 이동합니다.

ReLU의 이유

① W · Bias 조절

z=Wx₁+1·x₂+b → 경계 x₂=−Wx₁−b (x₂의 Weight=1 고정)

앞의 공통 W 예시와 다른 설정입니다. w₂=1 고정, w₁=W 조절로 W는 기울기를, b는 y절편을 바꿉니다.

② 직선과 AND 정답 비교

점 안의 0/1 = 정답 · 연한 초록 영역 = AI가 1로 판단한 위치

AND는 (1,1)만 1이어서 두 입력 Weight를 갖는 뉴런 하나의 직선만으로 네 점을 분리할 수 있습니다.

비선형성 · 깊어져도 직선이면?

가중합(Affine) 계산만 반복하면 하나의 가중합으로 다시 합칠 수 있습니다. 층을 늘리는 것만으로 XOR의 한계를 넘지는 못합니다.

ReLU의 이유

① 가중합 두 층을 연결

h = W₁x + b₁
z = W₂h + b₂

z = W₂(W₁x+b₁)+b₂

최종 경계는 여전히 한 직선

② 전개하면 하나의 계산

z = (W₂W₁)x
　 + (W₂b₁+b₂)

새 Weight = W₂W₁
새 Bias = W₂b₁+b₂

중간에 비선형 변환을 넣으면
하나의 Affine으로 합칠 수 없습니다.

두 층의 Weight와 Bias를 바꾸면 경계의 기울기와 위치가 달라집니다. 그래도 한 직선입니다. 다음은 반응을 꺾는 ReLU입니다.

ReLU · 비선형성의 시작

ReLU는 음수는 0으로, 0 이상은 그대로 통과시킵니다. 같은 축과 같은 눈금에서 0의 꺾임을 비교합니다.

ReLU 확대

ReLU(z)=max(0,z)는 0에서 꺾이는 비선형 함수입니다. 여러 반응을 조합하면 한 직선보다 복잡한 패턴을 표현할 수 있습니다.

단일 ReLU 하나만으로 XOR이 바로 해결되는 것은 아닙니다. 다음 실습은 두 ReLU를 조합한 |t|의 효과를 비교합니다.

XOR · 선형층을 쌓아도 직선 하나

가중합만 연결하면 경계의 기울기·위치는 바뀌어도 한 직선입니다. |t|를 사이에 넣어 꺾이는 경계와 비교합니다.

ReLU 효과

Layer 1

t=W₁x₁+x₂+b₁

Layer 2

z=W₂g(t)+x₁+b₂

g(t)=t일 때: z=(W₂W₁+1)x₁+W₂x₂+(W₂b₁+b₂)

점 안의 0/1 = 정답 · 연한 초록 영역 = AI가 1로 판단한 위치

|t|=ReLU(t)+ReLU(−t)는 두 ReLU 반응의 조합입니다. CNN도 Conv 사이의 비선형성으로 복잡한 패턴을 표현합니다.

Data Augmentation · 같은 정답, 다른 조건

분할을 끝낸 Train에서만, 정답 의미를 유지하는 밝기·회전 변형을 만듭니다.

변형 후에도 정답이 유효한지 확인합니다. 결함을 가렸다면 기존 결함 Label을 그대로 쓰지 않습니다.

동일 생성 사과의 화면 처리 시뮬레이션 · 파란 Box/Mask는 사람이 지정한 GT 예시 · Validation/Test는 정해 둔 평가 전처리를 유지합니다.

모델 학습 · 오차를 줄이는 반복

사진 + 정답 Label로 배우는 원리를, x=2 · y=4인 회귀 문제로 작게 확인합니다.

사과 사진 / Frame + 정답 Label: 불량→ Weight 계산은 아래 작은 회귀 문제로 단순화
발표자 노트: Batch는 한 번에 보는 사진 묶음. 6 images / Batch 2 = 3 Steps per Epoch. 2 Epochs = 6 Steps. 1 Batch → 1 Step(Weight 갱신). 사과 분류에는 실제 이미지와 정답 Label이 필요하며 이 회귀 수치는 CNN 실측 결과가 아니다.

입력과 정답은 고정하고 Weight를 바꿔 Loss를 줄입니다. 사과 분류는 Task에 맞는 별도 Loss를 사용합니다.

실제 경사하강 계산 · 사과 CNN 실험 아님 · ŷ=wx · Loss=(ŷ−y)² · η=0.1 · Bias=0 · 1 Batch → 1 Step

Loss · 틀린 정도를 줄이는 방향

Gradient는 어느 방향으로 얼마나 바꿀지, Optimizer는 실제 Weight 갱신을 담당합니다.

한 단계: w 0.5 → 1.7 · Loss 9 → 0.36. 입력과 정답은 바뀌지 않습니다.

교육용 단일 변수 회귀 계산 · CNN 결함 분류의 실측 Loss 아님

CNN 학습 · 예측에서 Weight 갱신까지

앞서 본 같은 CNN에서 Conv Kernel과 Dense Head의 W,b를 학습합니다.

Forward → Loss → Backward → Optimizer를 반복합니다. 초록 화살표가 닿는 세 블록만 Weight를 갱신합니다.

파랑: Forward · 갈색: Backprop Gradient · 초록: Optimizer Update · Label은 고정 정답 · 교육용 모델 개념도

Training과 Inference의 차이

배울 때는 정답으로 Weight를 바꾸고, 사용할 때는 고정된 Weight로 새 입력을 예측합니다.

Inference는 정답 Label 없이 수행합니다. 출력 raw Score는 보정된 확률을 보장하지 않습니다.

사진 / 디코딩된 동영상 Frame 입력 예시 · 학습·추론 흐름을 설명하는 자체 개념도

전이학습 · 특징은 고정하고 분류기만 학습

P20 같은 사과 CNN 구조로, 고정할 부분과 학습할 부분을 비교합니다.

먼저 Head를 학습하고 필요하면 일부 Conv를 미세조정합니다. 특징 재사용의 적합성은 Validation으로 확인합니다.

사전학습 모델을 재사용한다고 가정한 교육용 구조 · 사과 결함을 이미 학습했다는 뜻 아님 · 파라미터: Conv A 224 + Conv B 1,168 + Head 34

같은 CNN 특징 · 지도와 비지도 활용

두 경로 모두 하나의 고정 Backbone이 만든 같은 특징을 사용합니다.

지도: Label로 Head 학습. 비지도 후단: Label 없이 특징 군집화. Group A/B는 정상/불량을 뜻하지 않습니다.

고정된 사전학습 Backbone의 후단 활용 비교 · Backbone의 과거 사전학습에는 Label이 사용되었을 수도 있음 · CNN 전체의 두 학습법 비교 아님

Overfitting · 새 데이터 일반화

Train Loss가 계속 내려가도 Validation Loss가 다시 오르면 새 데이터 성능을 점검합니다.

학습 사진을 잘 맞히는 것만으로 충분하지 않습니다. 독립된 Validation 조건과 실패 사례를 함께 봅니다.

곡선은 교육용 가상 추세이며 실제 훈련 로그 아님 · 생성 사과의 화면 밝기 변환은 조명 취약성 가설용이며 실제 재촬영·측정 결과 아님

앞 실습의 기준을 0.50으로 고정한 참조 표입니다. 실제 불량 20건 중 18건을 찾고, 정상 80건 중 4건을 잘못 알렸습니다.
