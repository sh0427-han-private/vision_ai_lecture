01 · 문제 정의 핵심 개념

필요한 결과부터 정하면 Vision Task가 정해집니다

이미지 전체가 불량인지, 결함이 어디에 있는지, 정확한 면적이 얼마인지에 따라 필요한 결과가 다릅니다.

질문 → 결과 형태 → Task → Label → 평가 기준과 모델 순으로 연결합니다.

03 · Object Detection 핵심 개념

객체나 결함의 위치를 사각형으로 찾습니다

Object Detection(객체 검출)은 클래스·Bounding Box(경계 상자)·점수를 출력합니다.

Box 내부 전체가 결함인 것은 아닙니다. 상자는 위치를 둘러싸는 표현입니다.

형상·면적·경계가 필요하면 Box보다 Mask가 적합합니다.

05 · Label 핵심 개념

같은 사진이라도 Task가 바뀌면 정답 형태가 바뀝니다

분류는 이미지 클래스, 검출은 클래스와 Box, 분할은 Pixel Mask를 정답으로 사용합니다.

여기서 결과 그림을 정답으로 작성한 것이 Label이고, 모델이 계산한 것이 Prediction입니다.

06 · AI의 범위 핵심 개념

AI·머신러닝·딥러닝은 어떻게 다를까요?

AI는 넓은 기술 영역입니다. 머신러닝은 데이터에서 배우고, 딥러닝은 여러 층의 신경망으로 학습합니다.

Computer Vision(컴퓨터 비전)은 이미지·영상 문제를 다루는 분야입니다.

07 · 규칙과 학습 핵심 개념

판단 기준을 사람이 쓰거나, 데이터에서 배웁니다

규칙 기반은 사람이 조건을 정합니다. 학습 기반은 사진과 정답에서 판단 기준을 학습합니다.

실제 시스템에서는 영상처리 규칙과 학습 모델을 함께 사용하기도 합니다.

08 · 영상처리의 기본 핵심 개념

한 Pixel을 바꿀 수도, 주변 Pixel을 함께 볼 수도 있습니다

Point Operation은 픽셀 255를 min(255, 200)=200으로 제한합니다. Spatial Filtering은 중심 주변 3×3 값을 함께 사용합니다.

밝기 변환은 해당 Pixel 값으로 계산하고, 필터는 주변 값도 사용합니다. 이 연산 자체가 물체 이름을 예측하지는 않습니다.

11 · 영상 기울기 핵심 개념

밝기가 급격히 바뀌는 위치에서 경계 단서를 얻습니다

Sobel(소벨) 필터로 좌우·상하 밝기 변화를 계산합니다. 부호 있는 값을 계산한 뒤 절댓값과 크기로 시각화합니다.

두 기울기 그림은 같은 최대값으로 표시했습니다. 경계 반응은 밝기 변화의 단서이며, 그 자체가 물체나 결함의 정답은 아닙니다.

12 · 고정 필터와 학습 필터 핵심 개념

Spatial Filtering의 Kernel 개념은 CNN으로 연결됩니다

두 방법 모두 주변 Pixel을 계산하지만, 평균·Gaussian은 사람이 정한 고정 가중치이고 CNN 가중치는 데이터 학습으로 갱신됩니다.

이 그림은 고정 필터와 학습 필터의 개념적 비교이며, CNN의 실제 학습된 필터 값을 보여주는 것은 아닙니다.

13 · Perceptron 핵심 개념

입력마다 가중치를 곱하고, 더해서 하나의 판정을 만듭니다

Perceptron(퍼셉트론)은 입력에 가중치를 곱하고 Bias를 더해 판정합니다. 밝기와 모양을 사용한 가상 수치를 직접 계산합니다.

Weight는 입력의 기여도를, Bias는 합계의 기준 위치를 조절합니다.

14 · Neural Network 핵심 개념

여러 계산을 Layer로 연결하면 신경망이 됩니다

Neural Network(신경망)의 각 Layer(층)는 앞에서 받은 숫자를 조합해 다음 층으로 전달합니다.

그림의 노드·연결은 계산 구조를 나타내며, 실제 모델의 뉴런 수와는 다릅니다. 사진 1장을 입력하는 예시입니다.

15 · Activation 핵심 개념

Layer를 쌓을 때 비선형 계산도 필요합니다

Activation Function(활성화 함수)은 계산에 비선형성을 넣습니다. ReLU는 입력이 0보다 작으면 0, 크면 입력값을 그대로 출력합니다.

ReLU f(x)=max(0,x)는 x=0에서 그래프가 꺾입니다. 이것이 여러 Layer의 계산을 단순한 직선에서 벗어나게 할 수 있습니다.

16 · CNN 구조핵심 개념

CNN은 작은 영역에서 특징을 추출하고 조합합니다

실제 얼룩말 사진을 입력받아 필터(Convolution)와 Pooling을 거치며 특징을 추출하고, 마지막에는 Flatten·Fully Connected·Softmax를 통해 이미지의 종류를 분류하는 CNN 구조 예시입니다.

왼쪽은 특징 추출, 오른쪽은 이미지 분류입니다. 여러 Convolution Layer의 Kernel 가중치는 학습 데이터로 조정됩니다. 이 그림은 분류 CNN 예시이며 YOLO의 Detection Head와는 다릅니다.

원본 그림: Swapna K E · Developers Breach, Convolutional Neural Network (2020) · 그림 원본 열기 · 외부 접근 불가 시 기존 로컬 CNN 그림으로 자동 전환

17 · CNN 구조핵심 개념

CNN 블록을 이루는 세 계산: Conv·BN·ReLU

Convolution(합성곱)은 공간 특징을 계산하고, Batch Normalization(배치 정규화)은 값을 조정하며, ReLU(활성화 함수)는 비선형성을 제공합니다.

BatchNorm의 γ·β는 학습되는 값이고, 추론에서는 학습 중 누적된 통계값을 이용하는 것이 일반적입니다.

18 · CNN 핵심 개념

CNN은 작은 영역을 보고 같은 가중치를 재사용합니다

Convolutional Neural Network(합성곱 신경망)는 지역 연결과 가중치 공유로 이미지의 공간적 패턴을 계산합니다.

Flatten은 값과 순서를 유지하지만, 완전연결층에는 공간 이웃 관계와 가중치 공유가 명시되어 있지 않습니다.

19 · Kernel 핵심 개념

같은 필터도 이미지 영역에 따라 반응이 달라집니다

Kernel 또는 Filter(커널·필터)는 작은 가중치 배열입니다. 세로 밝기 변화가 있는 영역과 평평한 영역의 반응을 비교합니다.

그림은 사람이 정한 경계 필터 예시입니다. CNN의 필터 값은 학습으로 정해집니다.

20 · Feature Map 핵심 개념

반응값을 위치대로 모으면 특징 지도가 됩니다

5×5 입력에서 3×3 필터를 한 칸씩 이동하며 계산하면 3×3개의 반응값이 생깁니다. 이 값을 같은 위치에 모은 것이 Feature Map입니다.

Feature Map은 한 필터의 위치별 반응입니다. 이 예시에는 활성화 함수(ReLU)를 적용하지 않아 음수도 남아 있습니다.

21 · Feature Map과 Channel 심화 학습

RGB 전체를 보는 필터 하나가 출력 Channel 하나를 만듭니다

일반적인 Conv2d에서 필터 하나는 입력 Channel 전체를 곱해 합산합니다. 출력 Channel 수는 필터 수입니다.

3×3×3 필터 64개라면 가중치 1,728개와 Bias 64개이며, Stride 1·Padding 1의 출력은 224×224×64입니다.

22 · Stride 핵심 개념

필터를 몇 칸씩 이동할지 정합니다

Stride(이동 간격)가 1이면 한 칸, 2이면 두 칸씩 이동합니다. 같은 입력과 필터에서 이동 간격이 크면 출력 크기가 작아집니다.

5×5 입력과 3×3 필터, Padding 0: Stride 1은 3×3, Stride 2는 2×2 출력입니다.

23 · Padding 핵심 개념

가장자리 주변에 값을 채워 계산 범위를 조절합니다

Padding(패딩)은 입력 주위를 채우는 방법입니다. 아래는 가장자리 한 칸에 0을 채우는 Zero Padding입니다.

5×5 입력, Kernel 3·Stride 1·Padding 1이면 출력의 공간 크기가 5×5로 유지됩니다.

24 · Downsampling 핵심 개념

공간 해상도를 줄여 더 작은 특징 지도를 만듭니다

Downsampling(다운샘플링)은 가로·세로 크기를 줄이는 과정입니다. 아래는 2×2에서 최댓값을 남기는 Max Pooling 예시입니다.

8×8 → 4×4는 위치 수가 64개에서 16개로 줄어듭니다. 작은 결함이나 경계의 위치 정보가 일부 사라질 수 있습니다.

25 · 특징의 조합 핵심 개념

Layer는 앞의 특징을 조합해 더 복잡한 표현을 만듭니다

사과 이미지를 예시로 국소 밝기 반응 → 곡선·무늬의 조합 → 더 넓은 형태의 단서로 이어지는 개념적 특징 표현을 살펴봅니다.

국소 반응을 여러 Layer에서 조합한 개념도입니다. 실제 학습된 Feature Map이 항상 이 순서로 사람에게 해석되는 것은 아닙니다.

26 · Backbone과 Head 핵심 개념

특징을 만드는 부분과, 결과를 만드는 부분을 나눠 봅니다

같은 입력 특징을 추출하는 Backbone과, Classification·Detection·Segmentation 가운데 필요한 결과를 만드는 Task Head를 구분합니다.

세 가지 Head는 구조 비교를 위한 개념도입니다. 실제 한 모델이 항상 세 Task를 동시에 출력하는 것은 아닙니다.

27 · YOLO실전 개념

고정 필터는 사람이 정하고, YOLO의 필터는 학습합니다

Mean·Sobel처럼 사람이 설정하는 필터와 달리 YOLO의 합성곱(Convolution) 필터 가중치는 사진과 정답(Label)을 이용한 학습으로 조정됩니다.

CNN·YOLO는 유용한 패턴을 찾는 가중치를 학습합니다. 모든 전처리와 영상 문제를 자동으로 해결한다는 뜻은 아닙니다.

그림 참고: CNN Explainer · Ultralytics YOLO Architecture · 강의용 재구성

28 · YOLO실전 개념

YOLO는 Backbone → Neck → Head로 검출합니다

실제 YOLOv8 아키텍처 논문 Figure를 통해 Backbone(특징 추출), Neck(크기가 다른 특징 결합), Head(검출)의 연결을 확인합니다. 세부 모듈은 버전에 따라 다릅니다.

Backbone은 다양한 해상도의 Feature Map을 만들고, Neck은 이를 융합하며, Head는 Class·Box를 예측합니다. 이 Figure는 YOLOv8의 구체적 구조입니다.

29 · YOLO실전 개념

YOLO Detection의 출력은 Class·Box·Score입니다

사진 전체에서 물체의 종류(Class), 위치(Bounding Box, 경계 상자), 예측 점수(Score)를 함께 얻습니다. 그림의 결과는 실제 추론이 아닌 개념 예시입니다.

위치를 찾고 싶다면 Detection을 사용합니다. 출력 점수만으로 실제 현장 정확도가 보장되지는 않습니다.

그림 참고: Redmon et al. · You Only Look Once · CVPR 2016 · 강의용 재구성

30 · YOLO실전 개념

YOLO에서도 목적에 따라 Classify·Detect·Segment 모델을 선택합니다

이미지 전체의 종류가 필요하면 Classify, 사각형 위치가 필요하면 Detect, Pixel 영역이 필요하면 Segment 모델을 사용합니다.

YOLO라는 이름은 공통이지만 출력 Head와 학습 Label 형태가 다른 모델입니다. 하나의 Detect Weight가 자동으로 Segment Mask를 주지는 않습니다.

그림 참고: Ultralytics 공식 Task 문서 · Classify / Detect / Segment · 강의용 재구성

31 · YOLO실전 개념

YOLO 객체 검출은 종류와 위치를 함께 학습합니다

YOLO Detection은 객체가 무엇인지(Classification)와 어디에 있는지(Bounding Box)를 동시에 예측하고, 학습 중 각각의 정답과 비교해 오차를 줄입니다.

일반적인 YOLO 검출 모델은 분류만 학습하는 모델이 아닙니다. 클래스 예측과 박스 위치 예측을 함께 학습하며, 이미지 전체를 하나의 클래스로만 분류하는 YOLO Classification은 별도의 Task입니다.

32 · YOLO실전 개념

YOLO를 활용해도 데이터·Label·검증은 직접 준비해야 합니다

실제 사진과 정확한 Label을 모은 뒤 사전학습된 YOLO 모델을 내 데이터로 추가 학습하고, 새로운 조건의 영상으로 성능을 확인합니다.

학습은 Filter Weight를 조정하지만 촬영 환경, 데이터 품질, Train/Test 분리, 실패 사례 점검은 여전히 중요합니다.

33 · 학습의 의미 핵심 개념

학습은 예측 오차가 줄도록 계산 기준을 바꾸는 과정입니다

입력 x=2, 정답 y=4를 고정하고 학습을 진행합니다. 모델이 예측 오차를 줄이도록 가중치를 자동으로 수정하는 과정을 관찰하세요.

학습의 목적은 사람이 Weight를 임의로 조작하는 것이 아니라, 예측과 정답의 오차를 줄이도록 알고리즘이 Parameter를 갱신하는 것입니다.

34 · Loss 핵심 개념

Loss는 예측과 정답의 차이를 학습용 숫자로 바꿉니다

정답 y=4를 고정하고 후보 예측 2·3.6·4를 비교합니다. 회귀용 제곱오차는 차이의 부호를 없애고, 큰 오차에 더 큰 Loss를 부여합니다.

여러 샘플의 제곱오차를 평균하면 MSE(Mean Squared Error, 평균제곱오차)입니다. 문제에 따라 다른 Loss를 사용합니다.

개념 참고: Stanford CS231n · Optimization · 실제 계산한 단일 샘플 회귀 예시
35 · Training Loop 핵심 개념

예측 → 오차 → Gradient → 수정을 반복합니다

Training(학습)은 한 번의 계산으로 끝나지 않습니다. 바뀐 가중치로 다음 예측을 계산하고 다시 오차를 줄입니다.

Forward는 예측 계산, Backward는 Gradient 계산, Update는 가중치 수정입니다.

36 · Training과 Inference 핵심 개념

배울 때는 Weight를 바꾸고, 사용할 때는 고정합니다

Inference(추론)는 학습된 모델에 새 입력을 넣어 결과를 얻는 과정입니다. 정답 없이도 예측할 수 있습니다.

추론 과정 자체는 새로운 데이터로 가중치를 학습하는 과정이 아닙니다.

37 · Batch·Iteration·Epoch 핵심 개념

데이터를 작은 묶음으로 나누어 반복해서 봅니다

Batch는 한 번에 처리하는 묶음, Iteration은 보통 한 묶음의 처리, Epoch은 학습 데이터 전체를 한 번 보는 주기입니다.

이미지 10장, batch_size=4, 마지막 묶음을 버리지 않으면 4+4+2의 3번 처리가 1 Epoch입니다.

38 · CNN 학습 핵심 개념

CNN의 필터도 오차를 줄이는 방향으로 학습합니다

Forward로 예측하고 Label과 Loss를 비교한 뒤, Backpropagation으로 Gradient를 계산하고 Optimizer가 필터를 갱신합니다.

기본 학습 원리는 AI Basics와 같습니다. 학습하는 Parameter에 Kernel 가중치가 포함됩니다.

39 · Dataset 핵심 개념

데이터는 실제 사용할 조건을 대표해야 합니다

Dataset(데이터셋)은 학습·평가에 사용하는 데이터 모음입니다. 조명·크기·배경·설비·시간대와 일관된 정답 기준을 확인합니다.

특정 배경만 정답과 함께 반복되면, 모델이 물체 대신 배경으로 판단할 수 있습니다.

40 · 데이터 분리 핵심 개념

학습·모델 선택·최종 평가의 데이터를 나눕니다

Train은 가중치 학습, Validation은 모델·설정·Threshold 선택, Test는 최종 일반화 평가에 사용합니다.

예: 1,000장의 70/15/15 분리. 비율보다 서로 독립적인 평가 데이터 확보가 중요합니다.

41 · Group Split 핵심 개념

같은 영상의 비슷한 Frame은 통째로 분리합니다

동일한 원본 영상 A·B·C에서 각각 3개 Frame을 뽑은 예시입니다. 무작위 Frame 분할과 원본 Video를 통째로 나누는 Group Split을 비교합니다.

같은 원본 영상의 Frame이 Train·Validation·Test에 동시에 들어가지 않게 합니다. 새 설비 성능을 평가하려면 설비 자체로 Group을 정합니다.

42 · 전처리 핵심 개념

모델이 기대하는 크기·값 범위·채널 순서를 맞춥니다

Preprocessing(전처리)은 입력 형식을 맞추는 과정입니다. 1920×1080을 640×640으로 맞출 때는 Resize·Crop·Padding의 차이를 고려합니다.

RGB/BGR, 0~255/정규화 값, HWC/CHW를 확인하고 Train·Inference의 기본 규칙을 맞춥니다.

43 · Data Augmentation 핵심 개념

의미를 유지하는 변화를 학습 중에 보여줍니다

Data Augmentation(데이터 증강)은 밝기·회전·가림 같은 변화를 적용하는 방법입니다. 현실적인 변화 범위와 정답 유지 여부를 확인합니다.

검출·분할에서는 이미지와 Box·Mask에 같은 공간 변환을 적용해야 합니다.

44 · Transfer Learning 핵심 개념

이미 배운 가중치에서 내 Task의 학습을 시작합니다

사전학습으로 얻은 Backbone 가중치를 새 Task의 출발점으로 사용합니다. 새로운 Label에 맞춘 Head를 준비하고 대상 데이터에서 추가 학습합니다.

내 데이터가 사전학습 데이터와 다르면 효과가 달라질 수 있으므로 별도 평가가 필요합니다.

45 · Freeze와 Fine-tuning 심화 학습

고정할 부분과 추가 학습할 부분을 구분합니다

Freeze 방식은 Backbone 가중치를 고정하고 Head를 학습합니다. Fine-tuning에서는 선택한 Backbone 가중치까지 업데이트합니다.

같은 대상 데이터로 두 방식을 검증하고, 데이터 양·도메인 차이·Validation 성능에 따라 업데이트 범위를 선택합니다.

46 · Overfitting 핵심 개념

Train에서 잘하는 것과 새 데이터에서 잘하는 것은 다릅니다

Overfitting(과적합)은 학습 데이터에 지나치게 맞춰 새 데이터 성능이 떨어지는 현상입니다. Validation 추세와 실패 사례를 함께 봅니다.

Generalization(일반화)은 직접 학습하지 않은 데이터에서도 성능을 유지하는 능력입니다.

47 · Threshold 핵심 개념

점수에 기준을 적용하면 실제 판정이 됩니다

설명용 불량 점수 0.82를 기준 0.50과 0.90에 각각 적용합니다. 점수는 같아도 판정 결과는 바뀝니다.

임계값을 바꾸면 불량 미검과 오알람 수가 달라질 수 있습니다. 기준은 Validation에서 선택하며, 점수 0.82는 다음 100개 평가 사례와 별개입니다.

48 · Confusion Matrix 핵심 개념

정답과 판정을 비교해 네 가지 결과를 셉니다

총 100건의 같은 평가 데이터를 다음 지표 계산까지 이어갑니다. 실제 불량 20건 중 18건을 찾고, 정상 80건 중 4건을 잘못 알렸습니다.

TP: 찾은 불량 / FN: 놓친 불량 / FP: 오알람 / TN: 정상 통과.

49 · Precision과 Recall 핵심 개념

알람의 정확성과 불량을 찾는 비율을 구분합니다

직전 혼동행렬의 TP=18·FP=4·FN=2를 그대로 사용합니다. Precision은 불량이라고 알린 22건, Recall은 실제 불량 20건을 분모로 계산합니다.

동일한 TP=18이어도 Precision=18/22=81.8%, Recall=18/20=90%입니다. 임계값이 바뀌면 두 지표도 변할 수 있습니다.

50 · IoU 핵심 개념

위치와 영역은 정답과 얼마나 겹치는지 평가합니다

IoU(Intersection over Union, 교집합/합집합 비율)는 정답 영역과 예측 영역의 겹침 정도입니다.

완전 일치하면 1, 겹치는 영역이 없으면 0입니다.

51 · 평가와 실패 사례 핵심 개념

높은 점수만으로 판단 근거가 맞다고 보장할 수 없습니다

Vision AI에서 배경·조명·설비의 차이가 Class·Box·Mask 결과에 어떤 영향을 주는지 확인해야 합니다. 다른 조건의 이미지로도 판단 근거가 유지되는지 비교합니다.

분류 오판뿐 아니라 Box 위치·Mask 경계의 실패도 구분합니다. 설비별·조명별 오류 유형을 모아 모델이 바라본 단서를 점검합니다.

52 · 운영 Cycle 핵심 개념

문제 정의부터 운영 관찰까지 연결해 개선합니다

Vision Task별 성공 기준(분류 판정·Box 위치·Mask 품질)을 정하고, 운영 중 수집한 오류를 Label 검토 및 재평가로 연결합니다.

운영 Cycle에서는 Task별 Metric·오류 이미지·촬영 조건을 함께 추적하고, 개선 전후를 같은 기준으로 다시 평가합니다.

53 · 개발과 운영 핵심 개념

운영의 실패 사례를 다음 데이터와 학습에 연결합니다

배포 후에도 조명·설비·제품 조건이 바뀔 수 있습니다. 실패 이미지를 모으고 정답 기준과 평가 조건을 다시 확인합니다.

데이터 수집 → 학습 → 평가 → 배포 → 관찰을 반복하며 개선합니다.
