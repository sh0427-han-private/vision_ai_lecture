퍼셉트론 · Wx + b에서 판정까지

모델 내부의 계산을 가장 작은 단위로 봅니다. 퍼셉트론은 입력에 가중치를 곱해 모으고, 기준에 따라 0 또는 1을 출력하는 인공 뉴런입니다.

w : 입력의 영향과 방향b : 판정 기준 조정z = Wx + b : 판정 전 점수

고정 입력 1에 b를 곱하면 편향이 더해집니다. Wx+b 계산과 Step 판정을 합친 것이 퍼셉트론입니다. 위 예시는 두 입력이 모두 1일 때만 1을 출력하는 AND 게이트입니다.

Weight는 입력의 영향, Bias는 판정 기준을 조절합니다. Wx+b는 판정 전 점수이고 Step이 0/1을 출력합니다.

AND와 XOR · 직선으로 구분할 수 있을까?

AND는 두 입력이 모두 1일 때, XOR는 두 입력이 서로 다를 때 1입니다. 녹색 점은 출력 1, 회색 점은 출력 0입니다.

x₁x₂ANDXOR
0000
0101
1001
1110

AND: z = 0.5x₁ + 0.5x₂ − 0.7 · 경계 z=0 ⇔ x₁+x₂ = 1.4

AND는 직선 하나로 0과 1을 나눕니다. XOR는 어떤 가중치·편향을 골라도 단일 퍼셉트론으로 분리할 수 없습니다.

AND는 직선 하나로 구분하지만, XOR는 그렇지 않습니다. 더 복잡한 경계를 만들 이유가 여기에서 생깁니다.

ReLU · 비선형성의 시작

Activation Function(활성화 함수)은 계산에 비선형성을 넣습니다. ReLU는 입력이 0보다 작으면 0, 크면 입력값을 그대로 출력합니다.

차이는 음수 입력. 직선은 −2를 −2로 전달하지만, ReLU는 0으로 자릅니다. 이 꺾임을 조합하면 하나의 직선으로 표현할 수 없는 반응을 만들 수 있습니다.

ReLU가 0에서 반응을 꺾는 성질을 여러 뉴런에 조합하면, 한 직선보다 복잡한 패턴을 표현할 수 있습니다.

비선형성 · 깊어져도 직선이면?

더하고 곱하는 층을 여러 개 연결해도 한 번의 Affine 변환으로 합칠 수 있습니다. 중간의 ReLU가 이 한계를 바꿉니다.

ReLU가 없는 여러 층

전체가 하나의 Affine 계산과 동등

층 사이에 ReLU

구간에 따라 다르게 반응하는 함수를 조합

단순 그림은 이해용 도식이며 실제 신경망의 측정 그래프가 아닙니다. Step과 ReLU는 모두 비선형이고, 실제 신경망은 보통 ReLU 같은 활성화를 여러 층에서 반복합니다.

CNN에서도 작은 영역의 가중합(Conv) 사이에 ReLU를 넣어 더 복잡한 패턴을 표현합니다.

Kernel(커널)은 작은 가중치 배열입니다. 대응하는 값끼리 곱한 뒤 더하면 한 위치의 반응값 하나가 나옵니다.

실제 사진의 작은 영역을 수치로 생각하는 교육용 5×5 예제입니다. 아래 값은 위 사과 JPEG에서 직접 읽은 Pixel 값은 아닙니다.

위치별 가중합 계산을 Convolution(합성곱)이라 부릅니다. 딥러닝에서는 보통 Kernel을 뒤집지 않는 상관 연산 방식으로 계산합니다.

CNN · 지역 연결과 가중치 공유

큰 사진의 모든 Pixel을 서로 연결하는 대신, 작은 영역만 보고 같은 Kernel을 여러 위치에 반복 적용합니다.

정량 비교 조건: 단일 입력·출력 채널, 32×32, Kernel 3×3, Stride 1, Padding 1, Bias 제외. 세 방식의 표현력은 서로 같지 않습니다.

작은 영역만 계산하는 지역 연결, 같은 가중치를 재사용하는 공유가 CNN의 두 가지 핵심입니다.

입력 채널의 RGB는 색상이고, CNN의 출력 Channel은 학습된 특징에 대한 서로 다른 반응입니다.

Stride · 계산 위치의 간격

앞의 5×5 입력과 3×3 Kernel을 그대로 씁니다. Kernel의 왼쪽 위 시작 위치를 한 칸 또는 두 칸씩 이동합니다.

Stride 1 · 모든 유효 위치

출력 3×3 · 9개

Stride 2 · 두 칸씩

-616-47

시작 행·열: 각각 1, 3
출력 2×2 · 4개

출력 한 변 = ⌊(5 − 3) / Stride⌋ + 1

초록 위치가 Stride 2에서도 계산되는 위치입니다. 간격을 늘리면 계산량과 공간 크기가 줄고 촘촘한 위치 정보도 줄어듭니다.

바깥을 채우면 Kernel이 원본의 가장자리를 중심으로도 놓일 수 있습니다. 경계 효과를 보기 위해 입력은 1~9, Kernel은 모두 1인 3×3으로 바꿉니다. Stride는 1입니다.

Backbone과 Task Head

같은 사과 사진에서 특징을 모으는 부분이 Backbone입니다. 어떤 질문을 할지에 따라 마지막 Task Head의 출력이 달라집니다.

세 가지 Head는 구조 비교를 위한 개념도입니다. 실제 한 모델이 항상 세 Task를 동시에 출력하는 것은 아닙니다.

같은 사과를 화면상 변환한 교육용 비교입니다. 실제 데이터셋에는 정상·불량 모두 다양한 환경을 담고, 경계가 애매한 결함의 Label 기준도 미리 합의해야 합니다.

모델이 배워야 할 것은 배경이나 밝기가 아니라 결함에 필요한 특징입니다.

Train · Validation · Test

Train은 가중치 학습, Validation은 모델·설정·Threshold 선택, Test는 최종 일반화 평가에 사용합니다.

예: 1,000장의 70/15/15 분리. 비율보다 서로 독립적인 평가 데이터 확보가 중요합니다.

Video Group Split · 데이터 누출 방지

동일한 원본 영상 A·B·C에서 각각 3개 Frame을 뽑은 예시입니다. 무작위 Frame 분할과 원본 Video를 통째로 나누는 Group Split을 비교합니다.

같은 원본 영상의 Frame이 Train·Validation·Test에 동시에 들어가지 않게 합니다. 새 설비 성능을 평가하려면 설비 자체로 Group을 정합니다.

Preprocessing · 입력 규격 맞추기

사과의 작은 결함은 축소하면 사라질 수 있습니다. 이미지 크기를 바꾸는 전처리(Preprocessing)입니다. 앞의 강아지 사진을 정사각형으로 늘린 결과와, 비율을 유지하고 빈 공간을 채운 Letterbox를 비교합니다.

비율을 고려하지 않은 Resize는 객체 형태를 왜곡합니다. 크기·색 채널 순서·숫자 범위를 학습/추론에서 동일하게 맞춥니다. 사전학습 모델의 고정 정규화 규격은 그대로 쓰고, 내 데이터의 통계는 Train에서만 구합니다.

Data Augmentation · 조건 변화 만들기

Intro에서 본 밝기·회전·가림 변화에 대비하기 위해, 데이터 증강(Data Augmentation)으로 학습 입력을 다양하게 만듭니다. 같은 강아지 사진에 밝기·회전·가림을 적용한 실제 연산 결과를 비교합니다.

변환 후에도 Label이 맞아야 합니다. 결함을 가리거나 지워서는 안 되고, 색이 판정 기준이면 색상 변환도 제한합니다. 원본 그룹으로 먼저 분할하고 Train에 증강합니다. Box·Mask가 있는 회전·크롭은 Label도 함께 변환해야 합니다.

모델 학습 · 오차를 줄이는 반복

학습은 모델 내부의 숫자 Weight(가중치)를 바꾸는 과정입니다. 먼저 사진 대신 입력 x=2, 정답 y=4인 아주 작은 회귀 문제로 원리를 확인합니다.

이 예시는 하나의 숫자를 예측하는 회귀입니다. 사과 결함 분류도 예측과 정답의 차이로 가중치를 바꾸지만 Task에 맞는 다른 Loss를 사용합니다.

Loss · 틀린 정도를 줄이는 방향

방금 학습 실습의 숫자입니다. 예측과 정답이 다를 때 Weight를 어느 방향으로 바꿀지 Gradient가 알려줍니다.

입력과 예측

x=2 → ŷ=1

가중치 w=0.5

→

정답과 비교

y=4

Loss=(1−4)²=9

→

Gradient로 갱신

w=1.7

학습률 0.1
w′=0.5−0.1×(−12)

→

오차 감소

ŷ=3.4

Loss=(3.4−4)²=0.36

이 예시는 입력 x=2, 정답 y=4, Bias 0, 제곱 오차를 쓰는 교육용 회귀 문제입니다. 사과 결함 분류는 다른 Loss를 사용할 수 있습니다.

역전파(Backpropagation)는 각 Weight에 대한 Gradient를 계산하고, Optimizer는 그 값을 이용해 Weight를 갱신합니다.

Training과 Inference의 차이

Inference(추론)는 학습된 모델에 새 입력을 넣어 결과를 얻는 과정입니다. 정답 없이도 예측할 수 있습니다.

추론 과정 자체는 새로운 데이터로 가중치를 학습하는 과정이 아닙니다.

학습 과정에서 바뀌는 Kernel

작은 회귀 예시에서 w를 바꿨듯이, CNN은 Kernel의 가중치도 바꿉니다. Task에 맞는 예측과 Label의 차이가 학습 방향을 정합니다.

학습의 영향: 같은 사진이라도 Kernel 가중치가 바뀌면 Feature Map과 최종 예측이 달라질 수 있습니다. Gradient로 수정 방향을 계산하고 Optimizer(갱신 알고리즘)가 가중치를 갱신합니다.

전이학습 · 고정과 미세 조정

Transfer Learning(전이학습)은 이미 학습한 Backbone 가중치에서 시작하는 방법입니다. 새 Task의 Head를 준비하고 가중치를 어디까지 바꿀지 선택합니다.

Freeze는 Backbone을 고정하고 Head를 학습합니다. Fine-tuning은 선택한 Backbone도 갱신합니다. 학습에 쓰지 않은 검증 데이터(Validation)의 성능으로 선택합니다.

Batch · Step · Epoch

CNN을 학습시킬 때 사진을 몇 장씩 보고, 가중치를 몇 번 바꿨는지 읽기 위한 용어입니다.

Batch 1 · 4장
Batch 2 · 4장
Batch 3 · 2장
10장Train 전체 사진
3 StepBatch마다 한 번 Weight 갱신
2 Epoch = 6 Step전체 사진을 두 바퀴 학습

가정: Batch Size 4, 마지막 2장도 사용, Gradient 누적 없음. Parameter는 학습되는 Weight/Bias이고 Hyperparameter는 Batch Size·Learning Rate 같은 설정입니다.

Train Loss만 낮아졌다고 성공이 아닙니다. 새 데이터의 Validation 성능도 확인합니다.

Overfitting · 새 데이터 일반화

Overfitting(과적합)은 학습 데이터에 지나치게 맞춰 새 데이터 성능이 떨어지는 현상입니다. Validation 추세와 실패 사례를 함께 봅니다.

Generalization(일반화)은 직접 학습하지 않은 데이터에서도 성능을 유지하는 능력입니다.

Score Threshold · 판정 기준

설명용 불량 점수 0.82를 기준 0.50과 0.90에 각각 적용합니다. 점수는 같아도 판정 결과는 바뀝니다.

임계값을 바꾸면 불량 미검과 오알람 수가 달라질 수 있습니다. 기준은 Validation에서 선택합니다. Score 0.82가 실제 불량 확률 82%를 보장하지는 않습니다. 다음 100건과는 별도 예시입니다.

Confusion Matrix · 100건 평가

총 100건의 같은 평가 데이터를 다음 지표 계산까지 이어갑니다. 실제 불량 20건 중 18건을 찾고, 정상 80건 중 4건을 잘못 알렸습니다.

TP: 찾은 불량 / FN: 놓친 불량 / FP: 오알람 / TN: 정상 통과.

Accuracy의 함정 · 모두 정상이라면?

정상 80건, 불량 20건입니다. 전부 정상이라고 말해도 맞힌 비율이 80%가 됩니다.

80 / 100 = 80%모두 정상 예측
Accuracy
0 / 20 = 0%불량 20개를 전부 놓침
Recall
94% / 90%앞의 모델 정확도 / 불량 Recall

회색 80칸은 정상, 주황색 20칸은 실제 불량입니다. 이 비교는 앞의 같은 100건을 사용하며 모두 정상이라고 분류한 가상의 기준 모델을 추가한 것입니다.

검사의 목적이 불량을 찾는 것이라면 전체 Accuracy만이 아니라 놓친 불량(FN)과 Recall을 봐야 합니다.

Precision과 Recall

직전 혼동행렬의 TP=18·FP=4·FN=2를 그대로 사용합니다. Precision은 불량이라고 알린 22건, Recall은 실제 불량 20건을 분모로 계산합니다.

동일한 TP=18이어도 Precision=18/22=81.8%, Recall=18/20=90%입니다. 임계값이 바뀌면 두 지표도 변할 수 있습니다.

IoU · 박스 겹침 비율

분류의 정답 여부와 달리, 검출·분할에서는 위치나 영역도 맞아야 합니다. IoU(Intersection over Union)는 정답과 예측의 교집합/합집합 비율입니다.

완전 일치하면 1, 겹치지 않으면 0입니다. IoU만으로 검출 성능 전체를 판단하지 않습니다. 클래스·놓침·중복까지 평가하는 mAP(평균 정밀도 요약 지표) 등도 사용합니다.
