규칙 기반과 데이터 학습

조명만 달라도 같은 결함을 찾아야 한다면, 색상 기준 하나로는 부족할 수 있습니다. Machine Learning(머신러닝)은 데이터와 정답에서 판단 기준을 학습합니다.

AI는 큰 범주이고 머신러닝은 데이터로 기준을 학습하는 방식입니다. Deep Learning(딥러닝)은 여러 층의 신경망을 사용하는 머신러닝입니다.

모델 학습 · 오차를 줄이는 반복

학습은 모델 내부의 숫자 Weight(가중치)를 바꾸는 과정입니다. 먼저 사진 대신 입력 x=2, 정답 y=4인 아주 작은 회귀 문제로 원리를 확인합니다.

이 예시는 하나의 숫자를 예측하는 회귀입니다. 사과 결함 분류도 예측과 정답의 차이로 가중치를 바꾸지만 Task에 맞는 다른 Loss를 사용합니다.

Loss와 가중치 갱신

방금 본 첫 학습 단계입니다. Loss(손실)는 예측과 정답의 차이를 수치로 나타냅니다.

학습 전 · w=0.5

ŷ = 0.5 × 2 = 1
Loss = (1 − 4)² = 9

한 번 갱신 · w=1.7

ŷ = 1.7 × 2 = 3.4
Loss = (3.4 − 4)² = 0.36

Gradient(기울기)는 가중치를 어느 방향으로 바꿀지 알려줍니다.
학습률 0.1: w′ = 0.5 − 0.1 × (−12) = 1.7

예측 → Loss → Gradient 계산 → 가중치 갱신을 반복합니다. Learning Rate(학습률)는 한 번에 바꾸는 크기를 조절합니다.

Training과 Inference의 차이

Inference(추론)는 학습된 모델에 새 입력을 넣어 결과를 얻는 과정입니다. 정답 없이도 예측할 수 있습니다.

추론 과정 자체는 새로운 데이터로 가중치를 학습하는 과정이 아닙니다.

퍼셉트론 · Wx + b에서 판정까지

모델 내부의 계산을 가장 작은 단위로 봅니다. 퍼셉트론은 입력에 가중치를 곱해 모으고, 기준에 따라 0 또는 1을 출력하는 인공 뉴런입니다.

w : 입력의 영향과 방향b : 판정 기준 조정z = Wx + b : 판정 전 점수

고정 입력 1에 b를 곱하면 편향이 더해집니다. Wx+b 계산과 Step 판정을 합친 것이 퍼셉트론입니다. 위 예시는 두 입력이 모두 1일 때만 1을 출력하는 AND 게이트입니다.

여러 층을 거치는 두 입력

뉴런을 연결한 Neural Network(신경망)입니다. 입력층과 계산층을 구분하고, 우선 활성화 없이 곱셈과 덧셈만 해 봅니다.

h₁=x₁+x₂+1=4h₂=2x₁−x₂=0h₃=−x₁+2x₂=3
z₁=h₁+h₂+h₃=7z₂=2h₁−h₂+h₃=11

입력 (1,2)가 은닉층 두 개를 거쳐 출력 18이 됩니다. 출력층은 z₁+z₂만 계산합니다. 이 예시의 모든 계산층에서 활성화를 생략했습니다.

선형 계산만 쌓으면 단일층과 동등

이 신경망은 값을 대입하기 전에도 식 하나로 합칠 수 있습니다. 편향 b를 포함한 선형 계산(Affine)을 비교합니다.

은닉층 1의 세 값

h₁ = x₁+x₂+1
h₂ = 2x₁−x₂
h₃ = −x₁+2x₂

은닉층 2와 합산 출력

z₁ = h₁+h₂+h₃ = 2x₁+2x₂+1
z₂ = 2h₁−h₂+h₃ = −x₁+5x₂+2
y = z₁+z₂ = x₁ + 7x₂ + 3
입력 (1,2): 1 + 7×2 + 3 = 18

이 가중치에서는 모든 입력에 대해 같은 식이 성립합니다. 깊이만 늘려서는 직선으로 구분할 수 없는 문제를 해결하지 못합니다.

AND와 XOR · 직선으로 구분할 수 있을까?

AND는 두 입력이 모두 1일 때, XOR는 두 입력이 서로 다를 때 1입니다. 녹색 점은 출력 1, 회색 점은 출력 0입니다.

AND는 직선 하나로 0과 1을 나눕니다. XOR는 어떤 가중치·편향을 골라도 단일 퍼셉트론으로 분리할 수 없습니다.

다층 퍼셉트론 · 게이트 조합으로 XOR

은닉층의 Step은 이미 비선형 함수입니다. 층만 늘리는 것이 아니라 중간의 비선형 판정이 핵심입니다. ReLU도 비선형성을 넣는 다른 방법입니다.

ReLU · 비선형성의 시작

Activation Function(활성화 함수)은 계산에 비선형성을 넣습니다. ReLU는 입력이 0보다 작으면 0, 크면 입력값을 그대로 출력합니다.

차이는 음수 입력. 직선은 −2를 −2로 전달하지만, ReLU는 0으로 자릅니다. 이 꺾임 덕분에 여러 층이 하나의 선형층으로 합쳐지지 않습니다.

신경망의 핵심 · 계산 사이의 비선형성

Step과 ReLU는 모두 비선형 함수입니다. 실제 딥러닝에서는 가중합과 ReLU 같은 활성화를 반복해 복잡한 패턴을 표현합니다.

곱하고 더하기만

입력 → Wx+b → Wx+b → 출력

전체를 단일 Affine으로 합칠 수 있음

중간에 ReLU

입력 → Wx+b → ReLU → Wx+b

영역에 따라 달라지는 반응을 조합

y = W₂ ReLU(W₁x+b₁) + b₂

CNN도 같은 원리입니다. 이미지에서는 모든 Pixel을 한꺼번에 연결하기보다 작은 이웃 영역의 가중합을 반복합니다.

실제 Feature Map · CNN 내부 반응

실제 모델의 내부 반응을 확인하기 위해 공개 강아지 사진을 이미 학습된 CNN에 입력했습니다. 같은 사진에서도 층과 채널에 따라 다른 Feature Map이 만들어집니다.

얕은 층도 RGB 사진을 그대로 복사하지 않습니다. 각 채널은 학습한 특징에 대한 위치별 반응값이며, 채널별 색상 강도는 보기 쉽게 별도로 조정했습니다.

직접 계산: torchvision SqueezeNet 1.1 · ImageNet 사전학습 · 재현 코드 · 입력 사진: Stanford CS231n 2017 Lecture 5. 채널 4개만 선택, 색상은 채널별 상대값으로 정규화했습니다. 이 그림의 색은 채널 사이의 절대 반응 크기 비교에 사용할 수 없습니다.

학습 과정에서 바뀌는 Kernel

작은 회귀 예시에서 w를 바꿨듯이, CNN은 Kernel의 가중치도 바꿉니다. Task에 맞는 예측과 Label의 차이가 학습 방향을 정합니다.

학습의 영향: 같은 사진이라도 Kernel 가중치가 바뀌면 Feature Map과 최종 예측이 달라질 수 있습니다. Gradient로 수정 방향을 계산하고 Optimizer(갱신 알고리즘)가 가중치를 갱신합니다.

Backbone과 Task Head

같은 입력 특징을 추출하는 Backbone과, Classification·Detection·Segmentation 가운데 필요한 결과를 만드는 Task Head를 구분합니다.

세 가지 Head는 구조 비교를 위한 개념도입니다. 실제 한 모델이 항상 세 Task를 동시에 출력하는 것은 아닙니다.

전이학습 · 고정과 미세 조정

Transfer Learning(전이학습)은 이미 학습한 Backbone 가중치에서 시작하는 방법입니다. 새 Task의 Head를 준비하고 가중치를 어디까지 바꿀지 선택합니다.

Freeze는 Backbone을 고정하고 Head를 학습합니다. Fine-tuning은 선택한 Backbone도 갱신합니다. 학습에 쓰지 않은 검증 데이터(Validation)의 성능으로 선택합니다.

데이터셋 · 판정 기준과 촬영 조건

Dataset(데이터셋)은 입력과 Label의 모음입니다. 사과 결함 검사라면 결함 기준을 먼저 정하고, 실제 사용할 환경의 변화를 담아야 합니다.

Train · Validation · Test

Train은 가중치 학습, Validation은 모델·설정·Threshold 선택, Test는 최종 일반화 평가에 사용합니다.

예: 1,000장의 70/15/15 분리. 비율보다 서로 독립적인 평가 데이터 확보가 중요합니다.

Video Group Split · 데이터 누출 방지

동일한 원본 영상 A·B·C에서 각각 3개 Frame을 뽑은 예시입니다. 무작위 Frame 분할과 원본 Video를 통째로 나누는 Group Split을 비교합니다.

같은 원본 영상의 Frame이 Train·Validation·Test에 동시에 들어가지 않게 합니다. 새 설비 성능을 평가하려면 설비 자체로 Group을 정합니다.

Overfitting · 새 데이터 일반화

Overfitting(과적합)은 학습 데이터에 지나치게 맞춰 새 데이터 성능이 떨어지는 현상입니다. Validation 추세와 실패 사례를 함께 봅니다.

Generalization(일반화)은 직접 학습하지 않은 데이터에서도 성능을 유지하는 능력입니다.

Preprocessing · 입력 규격 맞추기

입력 규격을 맞추는 전처리(Preprocessing)입니다. 앞의 강아지 사진을 정사각형으로 늘린 결과와, 비율을 유지하고 빈 공간을 채운 Letterbox를 비교합니다.

비율을 고려하지 않은 Resize는 객체 형태를 왜곡합니다. 전처리에서는 크기뿐 아니라 색 채널의 순서와 숫자의 범위도 학습 때와 동일하게 맞춥니다.

출처: Stanford CS231n (2017) 강아지 원본 사진 · NumPy/Pillow 계산 재현 코드 · 실제 이미지 연산 결과 (CNN 학습 출력 아님)

Data Augmentation · 조건 변화 만들기

데이터 증강(Data Augmentation)은 학습 입력에 다양한 조건을 만드는 방법입니다. 같은 강아지 사진에 밝기·회전·가림을 적용한 실제 연산 결과를 비교합니다.

변환 후에도 Label이 맞아야 합니다. 결함을 가리거나 지워서는 안 되고, 색이 판정 기준이면 색상 변환도 제한합니다. 그림은 같은 강아지 사진에 실제 변환을 적용한 연산 예시입니다.

출처: Stanford CS231n (2017) 강아지 원본 사진 · NumPy/Pillow 계산 재현 코드 · 실제 이미지 연산 결과 (CNN 학습 출력 아님)

Score Threshold · 판정 기준

설명용 불량 점수 0.82를 기준 0.50과 0.90에 각각 적용합니다. 점수는 같아도 판정 결과는 바뀝니다.

임계값을 바꾸면 불량 미검과 오알람 수가 달라질 수 있습니다. 기준은 Validation에서 선택하며, 점수 0.82는 다음 100개 평가 사례와 별개입니다.

Confusion Matrix · 100건 평가

총 100건의 같은 평가 데이터를 다음 지표 계산까지 이어갑니다. 실제 불량 20건 중 18건을 찾고, 정상 80건 중 4건을 잘못 알렸습니다.

TP: 찾은 불량 / FN: 놓친 불량 / FP: 오알람 / TN: 정상 통과.

Precision과 Recall

직전 혼동행렬의 TP=18·FP=4·FN=2를 그대로 사용합니다. Precision은 불량이라고 알린 22건, Recall은 실제 불량 20건을 분모로 계산합니다.

동일한 TP=18이어도 Precision=18/22=81.8%, Recall=18/20=90%입니다. 임계값이 바뀌면 두 지표도 변할 수 있습니다.

IoU · 박스 겹침 비율

분류의 정답 여부와 달리, 검출·분할에서는 위치나 영역도 맞아야 합니다. IoU(Intersection over Union)는 정답과 예측의 교집합/합집합 비율입니다.

완전 일치하면 1, 겹치는 영역이 없으면 0입니다.

과제를 시작할 때 선택할 개념

사과 결함 검사를 예로 강의 전체를 연결해 봅니다. AI 도구에 작업을 맡겨도, 결과와 검증 기준은 사람이 정해야 합니다.

질문필요한 개념이 사례의 선택
사진 전체가 결함인가?Task · Label분류 / 정상·결함 Label
작은 결함이 보이는가?해상도 · 전처리축소 후 결함 정보 확인
새 촬영에서도 통하는가?Group Split · 일반화촬영 묶음 분리 후 평가
무엇을 놓치면 안 되는가?Threshold · Recall미검출과 과검출의 비용 비교
운영 중 성능이 달라졌는가?오류 수집 · 재평가조건별 오류를 모아 Label·데이터 개선

검출이 필요하면 Box Label과 IoU, 분할이 필요하면 Mask Label과 영역 평가를 선택합니다. 개선 전후는 같은 평가 기준으로 비교합니다.
