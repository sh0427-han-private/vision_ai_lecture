## 원칙

기존 강의의 원본 영상·이미지·수치·슬라이드 링크를 삭제하지 않는다. 반복 설명을 무조건 없애지 않고, 같은 주제의 **개념 소개 장**, **실제 계산 장**, **실무 검증 장**이 서로 다른 질문에 답하도록 역할을 구분한다.

| 챕터 | 실제 전체 슬라이드 | 핵심 과정 | 심화 과정만의 추가 장 |

- **전체 과정(기본값):** `/docs/intro.html#slide-1` → 모든 기존 슬라이드 탐색
- **핵심 과정:** `/docs/intro.html?mode=core#slide-1` → `data-level="detail"`을 탐색 중 건너뜀
- 하단의 버튼을 누르면 학습 중 전체/핵심 모드 변경 가능. 슬라이드 삭제·번호 재설정 없이 동작함.
- 기존 직접 링크 `#slide-N`은 전체 모드에서 그대로 표시. 핵심 모드에서 심화 장으로 연결하면 다음 핵심 장으로 이동하도록 처리.
- 이전/다음 버튼, 목차·상단 챕터 이동 링크에서 `mode=core`가 유지됨.
- 기존 내용을 꼭 학습해야 하는 장에는 `data-level="basic"`을 유지하고, 정량·심화 풀이를 `detail`로 구분함.

## 검토한 중복·연결 구간

| 위치 | 이전 중복/부담 | 조정된 독립 역할 |
|---|---|---|
| Vision AI, Kernel 이동 → 평균 필터 계산 | 두 장의 핵심 문구가 모두 1053/9=117로 동일 | Kernel 이동 장은 서로 다른 위치에서 선택되는 9개 값과 **슬라이딩 과정**, 다음 Mean 장은 **가중합을 실제로 계산**하는 데 집중 |
| Vision AI, Gaussian 기본 → Mean 상세 | 핵심 모드에서는 Mean 상세가 생략돼 비교 기준이 약함 | Gaussian 기본 장에 **Mean은 동일 가중치**, **Gaussian은 가까운 Pixel 강조**를 함께 명시. 커널 상세는 전체 과정에서 제공 |
| Vision AI, Sobel 직관 → 이미지 Gradient | 경계 반응 설명 중복 | 전자는 3×3 **Sobel Gx 가중치 및 세로 경계 반응**, 후자는 **Gx·Gy를 결합한 경계 시각화**를 설명 |
| AI Basics, Feature·Representation ↔ Vision AI, Feature Map | 이미지 경계·특징을 여러 챕터에서 다시 소개 | AI Basics는 **특징을 수치로 표현**하는 일반 개념, Vision AI는 실제 **Convolution·Feature Map 계산**에 집중 |
| AI Basics, Shortcut Learning ↔ Vision AI, 평가와 실패 사례 | 배경·조명에 의존하는 현상을 중복 기술 | AI Basics는 **원치 않는 단서 학습의 개념**, Vision AI는 **Class/Box/Mask와 설비·조명별 실패 분석**으로 구분 |
| AI Basics, 개발과 운영 ↔ Vision AI, 운영 Cycle | 개발→배포→재학습 흐름 반복 | AI Basics는 일반 학습·평가·개선 순환, Vision AI는 **Task별 Metric, Label, 영상 조건과 운영 실패의 연계**로 구체화 |
| 두 강의의 개념 장과 심화 계산 장 | 같은 강의에서 난이도가 갑자기 급등 | "핵심 개념" / "심화 학습" 배지와 선택형 학습 경로 도입 |

## 구현 파일

- `docs/index.html`: 79장 핵심/99장 전체 경로 선택
- `docs/slide.js`: 모드 필터링, 표시 순서, 진행률, 직접 링크, 챕터 이동
- `docs/ai_basics.html`, `docs/vision_ai.html`: 하단 경로 전환 버튼과 개념/심화 배지, 반복 문구 차별화
- `docs/lesson.css`: 발표/모바일 화면 경로 전환 버튼 스타일
- `scripts/build_lesson_revision.py`: 재생성 시 버튼·배지·설명을 유지
- `scripts/verify_learning_routes.py`: Chromium에서 핵심 36/28장, 전체 44/40장, 상세 장 건너뛰기, 링크 처리, 챕터 사이 모드 유지 검사
- `.github/workflows/visual-audit.yml`: 198개 화면 캡처 후 핵심/전체 브라우저 테스트

## 검수 범위

학습 경로 테스트는 실제 Chromium 기반 이동을 확인하고, 시각 QA는 1366×768 / 1920×1080에서 현재 99장을 렌더링한다. 자동 검사는 모든 SVG 내부 글자/도형 간섭, 실제 프로젝터 가독성, 모바일 환경의 모든 해상도, 교육 내용 전체의 전문적 감수를 보장하는 것은 아니다.

기존 99장과 슬라이드 번호를 유지하도록 구현했기 때문에 학습 경로에 따라 **진행률 표시 분모만 달라진다.** 전체 모드에서는 원래 44/40장을, 핵심 모드에서는 36/28장을 표시한다.
