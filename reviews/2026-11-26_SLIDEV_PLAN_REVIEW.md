# Vision AI Slidev 개편 독립 검토

2026-11-26 · 구현 전 제안서 검토

서로 대화 기록을 공유하지 않은 EGM 리뷰어가 같은 제안서를 읽었습니다. 설계, 코드베이스 정합성, 구현 준비, 독자 이해, 문서 구조의 다섯 리뷰를 받았습니다. 장기 방향 전용 리뷰는 도구의 스레드 한도로 열리지 않았습니다.

| 주요 검토 의견 | 구현에 반영한 결정 |
| --- | --- |
| 임계값 실습과 최종 성능을 혼동하기 쉽습니다. FP·FN도 정의 전에 나옵니다. | P48은 한 사과의 알림 예로 시작하고 오류를 쉬운 한국어로 표시합니다. P48~51의 100건을 임계값 선택용 교육 예시로 명시하고, 다른 사과 그룹의 최종 평가 개념을 P54에서 연결합니다. |
| 픽셀, 합성곱, 학습, 평가 계산을 각각 구현하면 값이 갈릴 수 있습니다. | 원본 커밋을 고정하고, 기존 사진을 직접 읽는 픽셀 실습과 별도의 공통 수치 함수를 사용합니다. 회귀의 예측 1·손실 9에서 첫 갱신 1.7·손실 0.36, 합성곱 전체 맵, 임계값 동점 규칙과 같은 박스 좌표의 IoU를 검증합니다. |
| 기존 실제 특징 맵의 외부 사진을 별도 덱에 재배포할 근거가 불명확합니다. | 저장소의 사과로 SqueezeNet 추론을 새로 실행했습니다. 입력 이미지 해시, 가중치, 전처리와 출력 층을 기록했습니다. P08의 영상은 스틸 이미지 시뮬레이션으로 표시합니다. |
| 같은 사과를 다루더라도 분류·검출·분할의 경계와 여러 모델 사이의 관계가 모호합니다. | 교육용 사과 분류를 본 흐름으로 지정합니다. P14/P18의 대안 과제와 P52의 위치 평가는 목적을 밝혔습니다. P20의 가상 CNN 구조를 P36/P43에서 재사용하고, 작은 행렬과 실제 SqueezeNet 결과의 성격을 표시합니다. |
| 표지로 인한 장 번호 이동, Pages 하위 경로, 키보드 조작이 회귀할 수 있습니다. | 현행 매니페스트와 P번호·제목·순서를 대조하는 검사를 추가했습니다. 표지와 대표 8장의 기술 검수를 통과한 뒤 전체 제작을 진행했습니다. Pages 산출물에는 두 형식을 함께 넣고 Slidev는 해시 경로를 사용합니다. |
| 기술 검수만으로 120분과 수강생 이해도를 검증할 수 없습니다. | 대표 실습의 시연 분량을 발표자 노트에 표시하고, P55에 처음 보는 상황을 말로 설명하는 질문을 넣었습니다. 실제 수강생 테스트와 120분 리허설은 별도 검수로 남겼습니다. |
