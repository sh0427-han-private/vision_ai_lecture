# Vision AI 기초강의 · 현장 리허설 실행표

**상태: 리허설 준비 완료 / 실제 120분 발표 및 수강생 평가는 미실시.**

대상은 현재 Intro 11장 + Course 39장이다. 아래 시간은 `docs/two_hour_manifest.json`의 배분을 누적한 계획이며, 측정한 발표 소요시간이 아니다. 기술 검증 통과와 수강생의 이해 확인은 별도로 기록한다.

### CNN 30분 상세 배분

C8 전체 구조 2분 → C9 ROI/Kernel 5분 → C10 위치와 Feature Map 4분 → C11 지역 연결/공유 3분 → C12 RGB 병렬 필터 3분 → C13 Stride 3분 → C14 Padding 3분 → C15 Pooling 2분 → C16 실제 반응 3분 → C17 Head 2분 = **30분**.

C9에서는 실제 ROI와 교육용 5×5 배열의 경계를 먼저 설명한다. 첫 출력 −6만 직접 계산하고, C10에서는 다음 위치 12를 확인한다. 나머지 출력의 반복 계산으로 시간을 쓰지 않는다. C16 강아지 자료는 실측 CNN 반응을 보여주기 위한 별도 입력이며 사과 모델 결과가 아니다.

### 마지막 복습 6분 상세 배분

C35 전체 흐름 45초 → C36 Task/Label/조건/지표 45초 → C37 임계값 비교 90초 → C38 가설 실패 사례 60초 → C39 4질문 120초 = **6분**.

임계값은 0.50→0.30→0.70으로 선택한다. 놓친 불량 FN은 2→0→9, 오알람 FP는 4→30→2가 되어야 한다. 학습자에게 각 변화의 뜻을 먼저 말하게 한다. 실습 점수는 교육용이며 Test로 기준을 반복 선택하지 않는다.

## 이해도 확인표

각 문항은 그림을 가리키며 답한다. 암기한 용어 수보다 원인과 결과의 연결을 확인한다. 제안 판정은 항목당 0점(오개념/무응답), 1점(힌트를 주면 설명), 2점(독립적으로 설명)이다. **네 항목 모두 1점 이상**인지 확인하고, 0점 항목은 해당 그림을 다시 설명한다. 이 기준은 수업 운영용이며 검증된 교육 평가 척도는 아니다.

| 목표 질문 | 기대하는 최소 설명 | 바로잡을 오개념 | 실제 응답/점수 |
|---|---|---|---|
| 입력은 무엇인가? | 사진은 H×W 위치에 RGB 값 3개가 있는 숫자 배열. 축소 시 작은 결함 정보가 없어질 수 있음 | 확대하면 잃은 정보가 항상 복구됨 | 미실시 |
| 특징은 어떻게 찾는가? | 작은 영역의 가중합을 같은 Kernel로 옮겨 계산하면 Feature Map이 만들어짐 | Feature Map이 RGB 축소 사진 또는 사람이 그린 Mask임 | 미실시 |
| 어떻게 배우는가? | Prediction과 Label의 차이인 Loss를 줄이도록 Weight를 갱신함 | 추론할 때도 정답을 받아 Weight를 바꿈 | 미실시 |
| 어떻게 평가하는가? | 독립된 새 사진에서 FN/FP를 확인. Recall은 실제 불량 중 찾은 비율. 기준은 Validation에서 정하고 Test에 고정 | Accuracy만 높으면 충분함 / Test를 계속 보며 기준을 고름 | 미실시 |
